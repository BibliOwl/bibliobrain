# Rédaction

Français · [English](Writing-en.md)

L'onglet **Rédaction** vous aide à écrire un texte scientifique en y plaçant des références
**réellement soutenues** par vos documents. Il réunit un éditeur et le panneau
**Assistant**.

## Ce que propose l'assistant

Chaque action se lance avec son bouton **Lancer**. Elle porte sur le passage sélectionné
ou, sans sélection, sur tout le document.

| Action | Pour quoi faire |
|---|---|
| **Trouver des sources** | Articles de votre bibliothèque qui appuient le passage |
| **Relire** | Clarté, grammaire, ton |
| **Proposer des arguments** | Contre-arguments, limites, contexte |
| **Consulter un carnet** | Ce que vos carnets disent du passage |

## Ajouter des citations

1. Écrivez ou collez votre texte dans l'éditeur.
2. Sélectionnez un passage si vous voulez cibler la recherche (facultatif).
3. Dans **Trouver des sources > Options**, vous pouvez orienter la recherche (sujet,
   auteurs, mots-clés), cocher **Inclure les phrases déjà citées** pour chercher des
   sources complémentaires, et régler le **N° de 1ère citation** pour poursuivre une
   numérotation existante.
4. Cliquez sur **Lancer**. Les résultats arrivent phrase par phrase : vous n'avez pas à
   attendre la fin.
5. Placez une suggestion dans le texte, puis validez-la. **Tout placer**, **Valider ≥ 70 %**
   et **Rejeter les aperçus** traitent toutes les suggestions d'un coup.

### Ce qu'il faut savoir

- Une citation n'est proposée que si un passage de vos documents soutient vraiment la
  phrase.
- Une phrase trop vague, ou sans passage probant, ne reçoit **aucune** citation : c'est
  normal, pas une panne.
- Chaque suggestion montre la source, un extrait probant et une courte explication.

### Remonter à la source d'origine

Une suggestion tirée de votre bibliothèque a un bouton **Source d'origine ?**. Bibliobrain
relit le passage de l'article cité et regarde s'il attribue lui-même l'idée à une source
plus ancienne : « Cet article attribue cette idée à une source antérieure », avec les
références et le passage lu.

- **Remonter plus loin** refait la même vérification sur une de ces références, si elle
  est dans votre bibliothèque. La ligne **Plus ancienne source créditée trouvée** résume
  la chaîne.
- **Identifier** retrouve une référence hors bibliothèque sur Crossref (titre, revue,
  année, lien chez l'éditeur). Il faut avoir autorisé l'accès web dans les Paramètres ;
  seule la référence est envoyée, jamais votre texte.
- Le résultat n'est pas une preuve d'originalité. Avec un petit modèle, les attributions
  sont indicatives : vérifiez le passage.

## Relire et argumenter

- **Relire** propose des corrections, à **Appliquer** ou **Ignorer** une par une.
- **Proposer des arguments** suggère des pistes appuyées sur vos sources ; le **Type
  d'argument** se choisit dans les options. Une piste se place dans le texte comme
  phrase, paragraphe ou note de travail.

Les réponses suivent la langue de votre texte.

## Sur un passage sélectionné

Une barre apparaît au-dessus de la sélection : **Citer**, **Reformuler**, **Raccourcir**
et **Copier pour Word (Zotero)**, qui copie le passage avec des citations que le plugin
Zotero de Word reconnaît.

## Historique

**⋯ > Historique** garde les analyses précédentes et des versions du texte, enregistrées
toutes les 10 minutes et avant chaque modification groupée. **Restaurer** remet une
ancienne version ; le texte remplacé reste dans l'historique.

## Bibliographie et export

- **Copier** (menu **⋯** de l'éditeur) : copie le texte.
- **Exporter** : produit un fichier **Markdown**, **LaTeX** ou **BibTeX**.
- **Bibliographie** : une section sous l'éditeur liste toutes les références insérées ;
  **Copier toute la bibliographie** la copie d'un coup.

Votre brouillon est conservé entre deux sessions.
